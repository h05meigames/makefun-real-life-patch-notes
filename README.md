One-line patch note for a real-life bug, for make.fun's [Real-Life Patch Notes: The Comedy Changelog](https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d) bounty: the brain queues every embarrassing moment since 2009 and replays them at 3 a.m. with no skip button — fixed in v2.0.7.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, no dependencies) writes exactly one line — 128 characters, UTF-8, no trailing newline — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` for local runs). It validates the entry before writing: one line of 1–160 characters, opening with a version tag (`vX.Y.Z:`) and ending with a period, or it throws.
